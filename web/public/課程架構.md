%% 想到的先記下來，到時候再請AI幫忙整理順序 %%

基本條件
- 有自己的 Google 帳號（結尾是@gmail），並且要記得密碼
- 選擇任一 AI 平台，並且先下載安裝好程式（Codex/Claude 擇一）
- 在桌面上準備一個 *母* 資料夾，裡面放著不同講題的 *子* 資料夾

重要觀念
- 不會寫程式、看不懂怎麼辦？AI 就是最好的老師，直接問，請他用更好懂的方式解釋

## Lesson 1 上半（建立信心）

### 練習 0：確認環境沒問題

**目的**：確保 AI 工具正常運作，避免後面卡在環境問題。

**步驟**：
1. 打開 Claude Desktop / Codex Desktop
2. 開一個新對話，輸入：

```
你好，請告訴我今天是幾號？
```

3. AI 有回應 → 環境 OK，繼續練習 1
4. 沒有回應 / 出現錯誤 → 先告知講師

> [!tip] 遇到問題不要自己卡著
> 環境問題很常見，不是你的問題——告訴講師就好。

練習1：先讓 Codex/Claude 做一份表格

```
請研究 Codex或Claude(看你用什麼) 桌面版的新功能，整理成一份 Excel 表格。 表格欄位包含：功能名稱、用途、適合誰使用、使用情境、注意事項。 請把檔案存到這個專案資料夾。
```

> [!check] 練習完成？
> 表格已存到資料夾，欄位清楚列出你選的 AI 工具功能。

練習2：讓 Codex/Claude 幫你修改檔案

> [!note] 先計畫，再動手
> 給 AI 任務前，先問它「你打算怎麼做？」確認方向對了再讓它執行——這個習慣可以省掉 80% 的來回。

```
請刪除「注意事項」欄位，並把「適合誰使用」改成更白話的說法。
```

> [!check] 練習完成？
> 檔案已更新，可以看出「修改前」和「修改後」的差異。

## Lesson 2 上半（擴展能力）

> [!check] 練習完成？

練習5：安裝 plugin/skill 增加第三隻手

> [!warning] 費用提醒
> Google Calendar API 有免費配額，一般使用量不會超標。

#### 第一次使用：安裝 Google Calendar 串接

##### Claude 用法

在 Claude Code 對話框輸入：

```
請幫我安裝並設定 Google Calendar MCP，讓我可以在 Claude Desktop 直接讀取和新增行事曆事件。
```

Claude 會自動幫你安裝套件、寫入設定檔，並引導你完成 Google 帳號授權。

> [!tip] 只需要設定一次
> 授權完成後，重新啟動 Claude Desktop，之後就可以直接用。

##### Codex 用法

1. 點左側「**外掛程式**」
2. 找到 **Google Calendar** → 點「**+**」
3. 按照畫面完成 Google 帳號授權

> [!tip] 只需要設定一次
> 授權後，之後每次對話都可以直接操作 Google Calendar。

```
串接 google calender，將[講師課表.xlsx]裡面包含自己名字，通通加入行事曆，並且設定提醒
```

#### Claude 用法（需先安裝 Google Calendar MCP）

```
我要新增一個行事曆事件：
- 標題：[活動名稱]
- 日期：[YYYY-MM-DD]
- 時間：[HH:MM] 到 [HH:MM]
- 地點：[選填]
- 備註：[選填]

請直接幫我在 Google Calendar 建立這個事件，不要給我 .ics 檔案。
```

> [!tip] 還沒設定 MCP？
> 請先依照附件 [[whisper-skill-中文通用版]] 同樣的安裝邏輯，改安裝 Google Calendar MCP server，完成 Google 帳號授權後再來這個練習。

#### Codex 用法（透過 Google Calendar API）

```
請幫我用 Google Calendar API 新增一個行事曆事件：
- 標題：[活動名稱]
- 開始時間：[YYYY-MM-DDTHH:MM:SS+08:00]
- 結束時間：[YYYY-MM-DDTHH:MM:SS+08:00]
- 說明：[選填]

請完整寫出 Python 程式碼並直接執行，若需要授權請引導我完成 OAuth 流程。
```

> [!tip] 第一次需要授權
> Codex 會引導你完成 Google 帳號授權（OAuth），授權一次就好，之後每次都能直接建立事件。

> [!check] 練習完成？
> Google Calendar 上出現了你指定的事件（或 Codex 跑出執行成功訊息）。

練習6：外派助手進行繪圖

> [!warning] 費用提醒
> 繪圖使用 OpenAI gpt-image-2 API，每張圖約 $0.04-0.08 美元（約台幣 1-2 元）。建議先在 [OpenAI Platform](https://platform.openai.com/settings/organization/limits) 設定 Usage Limit，避免超支。

請幫我照著這份文件"draw-skill-中文通用版.md"完成安裝
```

完成後在專案資料夾內建立pptx（16:9），底圖鋪滿全頁，左半邊疊加文字 [一段聖訓]

```

> [!check] 練習完成？
> 有一張 AI 生成的圖片存到資料夾（或顯示在對話視窗）。

## Lesson 2 下半（個人化）

練習8：語音轉文字，省去打字時間，整理講者思維

> [!warning] 費用與隱私提醒
> - **費用**：Whisper API $0.006/分鐘，10 分鐘錄音約台幣 2 元。建議在 OpenAI Platform 設定 Usage Limit。
> - **隱私**：上傳前確認錄音中沒有身分證字號、電話等個人資料，錄音會傳送至 OpenAI 伺服器處理。

```
讀取資料夾裡的錄音檔，使用 whisper-1 模型轉成文字，輸出兩個檔案：
- 原文.md（完整逐字稿）
- 精華.md（去掉口語贅字、整理成段落、加小標題、附上時間戳）
```

> [!check] 練習完成？
> 資料夾裡出現了兩個檔案：逐字稿和整理版摘要。

練習9：請 AI 記住我的習慣，寫入 memory

寫入我的個人說明書（~/.claude/CLAUDE.md 或 ~/.codex/AGENTS.md），加在「## 我的習慣」區塊下。
